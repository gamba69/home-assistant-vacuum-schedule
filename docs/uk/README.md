# Vacuum Schedule

Vacuum Schedule — користувацька інтеграція Home Assistant для детермінованого розкладу робота-пилососа, pre-flight перевірок, WAIT, Dry-Run/REAL виконання, сповіщень, обслуговування, статистики та прогнозування.

## Публічна назва з 0.13.0

- Назва: **Vacuum Schedule**
- Domain: `vacuum_schedule`
- Каталог інтеграції: `custom_components/vacuum_schedule/`
- Репозиторій: `gamba69/home-assistant-vacuum-schedule`
- Actions/services Home Assistant: `vacuum_schedule.*`
- Шлях панелі: `/vacuum-schedule`

Попередня публічна назва `vacuum_scheduler` є legacy та використовується лише кодом одноразової міграції 0.12.61 → 0.13.0.

## Встановлення

Для нової інсталяції скопіюйте `custom_components/vacuum_schedule/` до каталогу `custom_components` Home Assistant і перезапустіть Home Assistant. Структура репозиторію підготовлена для додавання як custom repository HACS.

Під час оновлення з 0.12.61 встановіть 0.13.2, перезапустіть Home Assistant, додайте **Vacuum Schedule**, виберіть той самий пилосос і підтвердьте міграцію знайденого legacy-запису.

## Поточна модель

- **Schedule** задає повторювані локальні occurrence та коригування за днями тижня.
- Матеріалізований **JobInstance** представляє конкретний occurrence і зберігає його життєвий цикл.
- Зони прибирання пов'язують логічну зону планувальника з фізичною ціллю робота та містять правила зайнятості/доступності й номінальну площу.
- Pre-flight і WAIT відокремлені від фізичного виконання. Виправний blocker не витрачає occurrence до межі command-intent.
- Dry-Run проходить логіку scheduler/pre-flight/сповіщень без фізичних команд і без навчання REAL-статистики.
- Statistics Ledger та моделі прогнозів зберігаються незалежно від Home Assistant Recorder.
- Зовнішні фізичні запуски зберігаються, але навчають модель лише за надійної прив'язки цілі та профілю.
- Прогнозування суворо розділене за ефективним профілем прибирання; історія іншої конфігурації тієї самої зони не підмішується лише заради оцінки.

## Ручні та автоматичні запуски

- **Додатковий запуск** створює окремий manual Job і не витрачає наступний плановий occurrence.
- **Запустити раніше вручну** виконує вже наявний майбутній occurrence і зберігає його початковий ефективний профіль.
- **Смарт-запуск** виконує ще не використаний плановий occurrence поточного локального дня, а за його відсутності створює додатковий запуск.
- Runtime-команди доступні як actions Home Assistant у namespace `vacuum_schedule.*`.

## Локалізація

Починаючи з базової версії 0.12.61 документація проєкту синхронно ведеться **англійською, російською та українською**. Інтеграція Home Assistant і власна панель також постачають EN/RU/UK локалізацію.
